# 인게임 오버레이

<Badge type="warning" text="Windows 전용" />

게임 화면 위에 시계, 월드보스 정보, 파티 모집, 게임 시간 등을 겹쳐서 보여주는 기능이에요.

## 이런 걸 할 수 있어요

- 게임을 하면서 창을 전환하지 않고도 다음 정보를 확인
  - 시계(현재 시각)
  - 월드보스 HP 눈금자와 다음 보스 정보
  - 파티/부대 모집 글
  - 검은사막 인게임 시간
  - 알림(새 소식/모집 등)
- 원하는 위젯만 켜고 끄기, 위치와 투명도 조절
- 표시할 모니터 선택(멀티 모니터 환경 지원)

## 사용 방법

1. 홈 화면에서 오버레이 아이콘을 눌러 설정 화면으로 이동하세요.
2. 보고 싶은 위젯(시계, 월드보스, 파티 모집, 게임 시간, 알림)을 하나씩 켜세요.
3. "편집 모드"를 켜면 오버레이 위젯을 게임 화면 위에서 자유롭게 드래그해 위치를 옮길 수 있어요. 옮긴 위치는 자동으로 저장돼요. 위치를 처음 상태로 되돌리고 싶다면 "위젯 위치 초기화"를 사용하세요.
4. 각 위젯의 투명도를 조절해 게임 화면과 자연스럽게 어우러지도록 만들 수 있어요.
5. 여러 모니터를 사용한다면 오버레이를 띄울 모니터를 선택할 수 있어요.
6. 월드보스 위젯에서는 보스 이름 표시 여부를, 파티 모집 위젯에서는 표시하지 않을 모집 카테고리를 따로 설정할 수 있어요.

## 알아두면 좋은 점

- 오버레이는 게임 창과 별도의 투명 창으로 실행돼요. 평소에는 클릭이 그대로 게임으로 전달되고, 편집 모드일 때만 오버레이를 직접 클릭/드래그할 수 있어요.
- 오버레이를 켜면 위젯이 뜨기까지 약간의 시간이 걸려요. 켜자마자 안 보인다고 걱정하지 마세요.
- 연결된 모니터 구성이 바뀌면(예: 외부 모니터 연결 해제) 오버레이가 자동으로 주 모니터에 표시돼요.
- 앱을 완전히 종료하면 오버레이 창도 함께 닫혀요.
- 월드보스 정보는 [월드보스](/ko/features/world-boss/) 화면과, 파티 모집 정보는 [파티 찾기](/ko/features/party-finder/) 화면과 실시간으로 연동돼요.
