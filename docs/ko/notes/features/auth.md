# 로그인

Discord 계정으로 Karanda에 로그인하고, 검은사막 가문(Family)을 등록해 내 캐릭터로 인증할 수 있어요.

## 이런 걸 할 수 있어요

- Discord 계정으로 간편 로그인(별도 회원가입 절차 없음)
- 검은사막 가문(패밀리명) 등록/해제
- 게임 내에서 가문 소유자임을 직접 인증(소유 인증)
- 로그아웃 / 회원 탈퇴

## 사용 방법

### 로그인

1. 홈 화면 우상단의 로그인 버튼을 누르세요.
2. Discord 인증 화면으로 이동해요. Karanda가 요청하는 권한은 Discord 계정 식별(닉네임/아바타 확인) 뿐이며, 이를 허용하면 로그인이 완료돼요.
3. 한 번 로그인하면 직접 로그아웃하지 않는 한 다음 실행부터는 자동으로 로그인 상태가 유지돼요. 웹 버전은 페이지를 열 때마다 자동으로 로그인을 다시 시도해요.

### 가문 등록

1. 로그인 후 로그인 정보 화면에서 "가문 등록"을 선택하세요.
2. 지역(한국/북미/유럽/일본)과 가문명을 입력하고 등록하면, 등록한 가문 정보가 내 계정에 저장돼요.
3. 가문을 잘못 등록했거나 바꾸고 싶다면, 먼저 기존 가문을 해제한 뒤 새로 등록하세요. 한 계정에는 가문을 하나만 등록할 수 있어요.
4. 가문 정보를 최신 상태로 다시 불러오고 싶다면 새로고침(데이터 갱신)을 사용하세요.

### 가문 소유 인증

가문을 등록했다고 자동으로 소유자로 인정되는 건 아니에요. 실제로 그 가문의 주인임을 증명하려면 아래 절차를 거쳐야 해요.

1. 로그인 정보 화면에서 "소유 인증"을 시작하세요.
2. 화면에 안내된 항목(생활 스킬 또는 공헌도 잠금 중 하나)을 게임 안에서 실제로 잠가주세요.
3. 게임에서 설정을 마쳤다면 화면으로 돌아와 인증을 완료하세요.
4. 인증 시작 시점부터 **10분** 안에 완료해야 해요. 시간이 지나면 인증이 만료되어 처음부터 다시 시작해야 해요.

### 로그아웃 / 탈퇴

- 로그인 정보 화면에서 로그아웃하거나 회원 탈퇴를 진행할 수 있어요. 탈퇴하면 즉시 로그아웃되고 홈 화면으로 이동해요. 탈퇴는 되돌릴 수 없으니 신중하게 진행하세요.

## 알아두면 좋은 점

- 로그인 상태 확인 중 오류가 발생하면 서버 문제인지 토큰 만료인지 구분 없이 자동으로 로그아웃 처리될 수 있어요. 갑자기 로그아웃됐다면 다시 로그인해 보세요.
- Windows 앱은 로그인 시 기본 브라우저가 열리고 인증이 끝나면 자동으로 앱 화면(또는 Discord 채널)으로 돌아와요. 이 과정에서 PC의 8082 포트를 잠깐 사용하므로, 다른 프로그램이 이 포트를 이미 쓰고 있다면 로그인이 실패할 수 있어요.
- 소유 인증의 10분 제한시간은 화면에 표시되는 안내이고, 실제 만료 여부는 서버가 인증 시작 시각을 기준으로 판단해요.
