# 방송 위젯

OBS 같은 방송 프로그램의 "브라우저 소스"에 추가해서 쓰는 투명 배경 위젯이에요.

## 이런 걸 할 수 있어요

- 파트리지오(비밀 상점) 출현까지 남은 시간, 또는 이용 가능 여부 표시
- 방송 화면 위에 자연스럽게 겹쳐지는 투명 배경 위젯

## 사용 방법

1. OBS 등 방송 프로그램에서 "브라우저" 소스를 추가하세요.
2. URL에 Karanda 웹 주소의 방송 위젯 페이지(예: 파트리지오 위젯) 주소를 입력하세요.
3. 배경이 투명하게 처리되어 방송 화면에 위젯만 자연스럽게 표시돼요.

### 파트리지오 위젯

- 파트리지오는 게임 내 시간 기준으로 **00:40, 04:40, 08:40, 12:40, 16:40, 20:40**마다 출현해요.
- 게임 시간이 밤(22시~다음 날 10시)이면 초록색 테두리와 함께 "비밀 상점 이용 가능!!" 안내가 표시돼요.
- 낮 시간이면 다음 출현까지 남은 시간이 표시돼요(1분 미만은 초 단위, 그 이상은 분 단위).

## 알아두면 좋은 점

- 위젯은 배경이 투명해야 방송에 자연스럽게 합성돼요. OBS의 브라우저 소스 설정에서 배경색을 별도로 지정하지 마세요.
- 로그인 없이 바로 사용할 수 있어요.
- 시계처럼 단순한 시간 표시 위젯도 준비되어 있으며, 앞으로 더 다양한 방송용 위젯이 추가될 예정이에요.
