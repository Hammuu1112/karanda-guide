# 설정

앱의 테마, 폰트, 지역, 알림, Windows 동작 방식 등을 원하는 대로 바꿀 수 있어요.

## 이런 걸 할 수 있어요

- 테마(라이트/다크/시스템), 폰트, 배경음/효과음 볼륨 조절
- 게임 지역(한국/북미/유럽/일본) 설정 — 거래소, 월드보스, 뉴스 등 지역 기반 기능에 함께 적용
- <Badge type="warning" text="Windows 전용" /> 시작 시 최소화, 트레이 상주 여부 설정
- 뉴스·월드보스 등 알림 켜기/끄기와 알림 카테고리 선택
- 후원 안내, 변경 이력, 앱 정보 확인

## 사용 방법

### 화면/사운드

- 테마는 라이트/다크/시스템(내 기기 설정 따르기) 중 선택할 수 있고, 기본값은 **다크 모드**예요.
- 폰트는 메이플스토리체·본고딕·나눔고딕·주아체 중에서 고를 수 있어요. 기본값은 본고딕(Noto Sans KR)이에요.
- 배경음/효과음 볼륨은 0~100 사이에서 슬라이더로 조절해요.

### 지역

- 지역 기본값은 **한국(KR)**이에요. 북미/유럽/일본으로 바꾸면 [거래소 시세](/ko/features/trade-market/), [월드보스](/ko/features/world-boss/), [뉴스](/ko/features/news/), [파티 찾기](/ko/features/party-finder/) 등 지역별로 동작하는 모든 기능이 바뀐 지역 기준으로 함께 갱신돼요.

### Windows 전용 설정

- "시작 시 최소화"를 켜면 앱을 실행했을 때 창이 최소화된 채로 시작돼요.
- "트레이 상주"를 켜면 창을 닫아도 앱이 종료되지 않고 트레이에 남아있어요. 두 옵션 모두 기본값은 꺼짐이에요.

### 알림

1. 알림 설정 화면(웹/안드로이드는 "푸시 알림", Windows는 "알림")으로 이동하세요.
2. 뉴스 알림을 켜고, 받고 싶은 카테고리(공지/업데이트/이벤트/연구소)를 선택하세요. 기본값은 모두 꺼짐이에요.
3. 웹/안드로이드에서는 알림을 켜는 순간 브라우저/기기의 알림 권한을 요청해요. 권한을 거부하면 알림이 켜지지 않으니, 알림이 오지 않는다면 기기의 알림 권한 설정을 먼저 확인해 보세요.
4. [월드보스](/ko/features/world-boss/), [파티 찾기](/ko/features/party-finder/) 알림은 각 기능 화면의 설정에서 별도로 켤 수 있어요.

### 기타 페이지

- "후원하기": Karanda 후원 방법 안내
- "변경 이력": 버전별 업데이트 내역
- "앱 정보": 현재 버전 등 앱 정보 확인

## 알아두면 좋은 점

- 지역을 바꾸면 여러 기능에 한꺼번에 영향을 주니, 다른 서버 정보를 보고 싶을 때만 바꿔주세요.
- Windows에서의 창 크기/위치는 홈 화면을 사용하는 동안 자동으로 저장돼요. 설정 화면에서 직접 입력하는 값이 아니에요.
- 알림 권한이 거부된 상태에서는 알림 스위치를 켜도 아무 반응 없이 꺼진 상태로 남을 수 있어요. 이 경우 화면상 스위치 상태와 실제 수신 여부를 다시 확인해 보세요.
