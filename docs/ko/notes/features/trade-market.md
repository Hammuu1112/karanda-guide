# 거래소 시세

검은사막 거래소의 실시간 시세와 등록 대기 목록을 확인하고, 자주 찾는 아이템 모음(프리셋)을 빠르게 조회할 수 있어요.

## 이런 걸 할 수 있어요

- 아이템 이름으로 검색해 시세 상세 보기(강화 단계별 가격 추이 포함)
- 거래소에 등록 대기 중인 아이템 목록 실시간 확인
- 별의 노래, 마력이 깃든 라이트스톤 결정, 데키아의 빛, 여명의 정수 등 자주 쓰는 프리셋 모음 시세 한눈에 보기
- 요리상자 재료를 내 숙련도/공헌도 기준으로 계산

## 사용 방법

### 검색 및 시세 상세

1. 거래소 화면에서 아이템 이름을 입력하면 검색 결과가 실시간으로 나타나요(띄어쓰기 무시, 부분 일치).
2. 원하는 아이템을 선택하면 상세 화면으로 이동해요. 강화 단계(0강~5강 등)별로 최고가/최저가/중간가와 가격 추이를 확인할 수 있고, 강화 단계를 눌러 바꿔볼 수 있어요.
3. 상세 화면 상단에서 지역(한국/북미/유럽/일본)을 바꿔 다른 서버 시세도 조회할 수 있어요.

### 등록 대기 목록

- 거래소 메인 화면에서 실시간으로 갱신되는 등록 대기 아이템 목록을 볼 수 있어요. 거래소에 아직 등록되지 않은(비매각) 아이템은 목록에 나타나지 않아요.
- [설정](/ko/features/settings/)에서 지역을 바꾸면 대기 목록도 해당 지역 기준으로 다시 연결돼요.

### 프리셋

1. 상단 메뉴에서 원하는 프리셋(별의 노래, 마력이 깃든 라이트스톤 결정, 데키아의 빛, 여명의 정수)을 선택하세요.
2. 프리셋에 포함된 아이템들의 최신 시세가 한 번에 조회돼요. 재고가 있는 아이템이 먼저, 재고 유무가 같으면 단가가 저렴한 순으로 정렬돼요.

### 요리상자 계산

1. 요리상자 프리셋 화면으로 이동하세요. 6종류 상자 중 하나를 선택할 수 있어요(기본값: 재료비 상자).
2. 내 공헌도(기본값 200)와 숙련도(기본값 1200)를 입력하세요.
   - **납품 가능 횟수 = 공헌도 ÷ 2**로 자동 계산돼요.
   - 숙련도에 따라 은전 보너스 구간이 정해져요.
3. 재료 목록도 재고 유무와 총 비용(단가×필요 수량) 기준으로 정렬돼서 표시돼요.

## 알아두면 좋은 점

- 조회되는 기본 지역은 [설정](/ko/features/settings/)의 지역 값을 따라요. 다른 서버 시세를 보려면 상세/프리셋 화면에서 지역을 직접 바꿔주세요.
- 웹 버전에서는 등록 대기 목록 화면을 벗어나면 실시간 연결이 끊겨요. 다시 화면에 들어오면 자동으로 재연결돼요(데이터 절약을 위한 동작). Windows 앱에서는 화면을 벗어나도 연결이 유지돼요.
- 시세 상세의 "최신가"는 항상 가장 최근 날짜의 가격이에요.
- 공헌도 2당 요리상자 1개를 납품할 수 있다는 게임 사양이 그대로 반영돼 있어요.
