# 색 카운터

빨강·노랑·파랑·흰색 네 가지 색상의 개수를 간단히 세어볼 수 있는 보조 도구예요.

## 이런 걸 할 수 있어요

- 인게임에서 색상 개수를 셀 때 빠르게 탭해서 카운트

## 사용 방법

1. 원하는 색상 박스를 탭하면 숫자가 1씩 늘어나요(상한 없음).
2. 박스 아래 버튼을 누르면 1씩 줄어들어요(0 아래로는 내려가지 않아요).
3. 우측 하단 새로고침 버튼을 누르면 네 색상 모두 0으로 초기화돼요.

## 알아두면 좋은 점

- 입력한 숫자는 저장되지 않아요. 다른 화면으로 이동하면 다시 0부터 시작해요. 게임 도중 잠깐 세어볼 때 쓰는 가벼운 도구예요.
- 화면을 가로로 넓게 쓰면 박스가 가로로, 세로로 길게 쓰면 세로로 배치되는 등 화면 비율에 맞게 자동으로 정렬돼요.
