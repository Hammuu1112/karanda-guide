# 물물교환

물물교환(바터)에 필요한 결정(파레이) 소모량과 교역품 무게를 계산해 주는 도구예요.

## 이런 걸 할 수 있어요

- 여러 교환처를 조합했을 때 소모되는 파레이(결정) 총량 계산
- 교역 증서 사용, 밸류팩/클레이아/교역 숙련도에 따른 파레이 절감 효과 반영
- 교역품을 배에 실을 때 필요한 무게 계산

## 사용 방법

### 파레이(결정) 계산

1. 우상단 설정에서 내 교역 숙련도, 밸류팩 사용 여부, 배 프로필(클레이아 사용 여부 포함)을 입력하세요. 이 값에 따라 각 교환처의 실제 소모량이 자동으로 줄어들어요.
   - 절감률은 **교역 숙련도 절감률 + 밸류팩 10% + 클레이아 10%**를 모두 더한 값이에요. 조건을 여러 개 켤수록 절감 효과가 누적돼요.
2. 기본 보유 파레이는 **1,000,000**이에요. 교역 증서를 가지고 있다면 장수(0~99장)를 입력하세요. 1장당 **250,000**씩 늘어나요.
3. 사용할 교환처별로 횟수(0~999)를 입력하면 그 교환처에서 소모될 파레이가 자동으로 계산돼요.
4. "적용" 버튼을 누르면 해당 교환처의 소모량이 누적 소모량에 더해지고, 입력한 횟수는 0으로 초기화돼요.
5. 처음부터 다시 계산하려면 초기화 버튼을 누르세요. 보유 파레이가 1,000,000으로 되돌아가요.

### 무게 계산

1. 무게 계산 탭으로 이동하세요.
2. 단계별(1단계~7단계) 교역품 개수를 입력하면 단계별 산출 무게(100~2000)를 기준으로 전체 무게가 자동 계산돼요.
3. 목록에 없는 교역품은 "기타" 항목에 무게를 직접 입력할 수 있어요.
4. 초기화하면 다른 단계는 모두 0으로, 기타 항목만 기본값(1개)으로 되돌아가요.

## 알아두면 좋은 점

- 파레이 절감 계산식과 교역 증서 1장당 250,000이라는 값은 게임 공식 사양을 그대로 반영한 값이에요.
- 배 프로필은 최소 하나는 항상 남아 있어요. 여러 배를 등록해 두고 상황에 맞게 선택해서 쓸 수 있어요.
- 교환처 목록과 필요 파레이 수치는 게임 패치로 바뀔 수 있고, 그에 맞춰 앱도 함께 갱신돼요.
