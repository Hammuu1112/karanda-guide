# 뉴스

검은사막 공식 공지·업데이트·이벤트와 연구소(LAB) 소식을 한 곳에서 확인하고, 새 소식을 실시간 알림으로 받을 수 있어요.

## 이런 걸 할 수 있어요

- 최신 주요 업데이트, 연구소 소식 확인
- 진행 중인 이벤트 목록 확인 (마감일까지 남은 기간 표시)
- 등록일순 / 마감일순으로 이벤트 정렬, 상시 이벤트 포함 여부 선택
- 새 소식 실시간 알림 받기

## 사용 방법

1. 뉴스 화면 상단에서 최신 주요 업데이트와 연구소 소식 카드를 확인하세요. 소식이 없으면 해당 카드는 보이지 않아요.
2. 그 아래 이벤트 목록에서 각 이벤트의 마감까지 남은 기간이 "D-N" 배지로 표시돼요. 마감이 3일 이내로 임박하면 빨간색으로, 아니면 파란색으로 강조돼요. 마감일이 없는 상시 이벤트는 "상시"로 표시돼요.
3. 목록 우측의 필터 아이콘을 눌러 정렬 방식을 바꿀 수 있어요.
   - **등록일순**(기본값): 최근 등록된 이벤트가 먼저 보여요.
   - **마감일순**: 진행 중인 이벤트는 마감이 임박한 순으로, 종료된 이벤트는 최근 종료한 순으로 그 뒤에 이어져요.
   - **상시 포함** 체크박스(기본값 켜짐): 체크를 해제하면 상시 진행 이벤트가 목록에서 숨겨져요.
4. 관심 있는 소식을 누르면 검은사막 공식 페이지로 이동해요.
5. 아래로 당겨서 새로고침하면 최신 소식을 다시 불러와요.
6. 알림을 받고 싶다면 [설정](/ko/features/settings/)의 알림 항목에서 뉴스 알림을 켜고, 받고 싶은 카테고리(공지/업데이트/이벤트/연구소)를 선택하세요.

## 알아두면 좋은 점

- 홈 화면에도 마감이 임박한 이벤트(1~3일 남음)가 있으면 "마감 임박 이벤트"로 우선 보여줘요. 없으면 최신 이벤트 5개가 "이벤트"라는 제목으로 표시돼요.
- 마감일 당일(D-0)은 "진행 중"이 아니라 "종료"로 처리돼요. 이미 종료된 이벤트는 목록에서 사라지지 않고 흐리게 표시된 채로 남아 있어요.
- 뉴스 알림은 기본적으로 꺼져 있어요. [설정](/ko/features/settings/)에서 직접 켜야 알림을 받을 수 있어요.
- 연구소(LAB) 소식은 특정 지역과 무관하게 공통으로 제공돼요.
- 이벤트 목록에 표시되는 마감일은 크롤러가 최초로 감지한 게시일을 기준으로 계산해요. 실제 이벤트 시작일과 다를 수 있어요.
