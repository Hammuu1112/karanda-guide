# 예약 종료

<Badge type="warning" text="Windows 전용" />

지정한 시각에 컴퓨터가 자동으로 종료되도록 예약할 수 있는 기능이에요.

## 이런 걸 할 수 있어요

- 원하는 시각(시:분)을 지정해 컴퓨터 자동 종료 예약
- 예약 취소
- 예약된 경우 종료까지 남은 시간 실시간 확인

## 사용 방법

1. 예약 종료 화면에서 원하는 시각(시:분)을 선택하세요.
2. "시작" 버튼을 누르면 예약이 등록되고, 종료까지 남은 시간이 실시간 카운트다운으로 표시돼요.
3. 예약을 취소하려면 빨간색 "취소" 버튼을 누르세요. 다시 시작 버튼으로 바뀌어요.

## 알아두면 좋은 점

- 선택한 시각이 이미 지났거나 1분도 안 남았다면, 자동으로 다음 날 같은 시각으로 예약돼요. 예를 들어 지금이 밤 11시 59분인데 밤 11시 55분을 선택하면 내일 밤 11시 55분으로 예약돼요.
- 종료는 강제 종료 방식으로 실행돼요. 예약 전에 진행 중인 작업(문서 저장 등)을 미리 마쳐두세요.
- 앱을 껐다 켜면 예약 화면은 이전 예약 상태를 그대로 보여줘요. 다만 실제 종료 예약 자체는 Windows가 별도로 관리하고 있어서, 예약 상태가 맞는지 의심스럽다면 한 번 취소했다가 다시 걸어주는 게 확실해요.
- 관리자 권한 제한이 있는 PC 환경에서는 종료 명령이 정상 동작하지 않을 수 있어요.
