# 배 강화

카론/대양선 등 선박 강화에 필요한 재료 수량을 계산하고, 내가 가진 재고 대비 진행률을 추적할 수 있어요.

## 이런 걸 할 수 있어요

- 선택한 선박의 전체 부품/재료 필요 수량 확인
- 아직 완성하지 못한 부품 기준으로 남은 재료(잔여 필요량)와 충족률 확인
- 재료별 보유 수량 입력 및 관리(최대 9999개)
- 일일 퀘스트로 얻는 재료를 버튼 한 번으로 일괄 반영

## 사용 방법

1. 화면 상단에서 강화하려는 선박을 선택하세요.
2. 선박에 필요한 부품과, 각 부품에 필요한 재료 목록이 표시돼요. 재료별로 현재 보유 수량을 직접 입력하거나 +/- 버튼으로 조정하세요.
3. "일일 퀘스트" 버튼을 누르면 일일 퀘스트로 매일 얻는 17종 재료의 정해진 수량만큼 한 번에 더해져요. 매일 퀘스트를 완료했다면 이 버튼만 눌러주면 재고 입력이 끝나요.
4. 부품의 재료가 모두 채워지면 해당 부품은 완성으로 표시돼요. 완성된 부품에 쓰인 재료는 화면 상단의 진행률(충족률) 계산에서 제외돼서, 아직 완성하지 못한 부품에만 집중할 수 있어요.

## 알아두면 좋은 점

- 입력한 재고 수량은 자동으로 저장돼서, 앱을 껐다 켜도 그대로 남아 있어요.
- 재료 보유 수량은 최대 9999개까지 입력할 수 있어요. 그 이상은 더 늘어나지 않아요.
- 이미 완성으로 표시된 부품의 재료는 진행률 계산에 포함되지 않으니, 전체 진행률이 100%가 아니어도 이상한 게 아니에요(완성한 부품 몫은 이미 제외됐기 때문).
- 게임 업데이트로 선박/부품/필요 재료가 바뀌면 화면의 계산 내용도 그에 맞춰 갱신돼요.
