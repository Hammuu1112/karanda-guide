# 홈 화면

Karanda를 실행하면 가장 먼저 보이는 대시보드예요. 로그인부터 각 기능 이동, 최신 소식 확인까지 여기서 다 할 수 있어요.

## Karanda가 제공하는 기능

홈 화면 가운데에는 아래 기능들로 바로 이동할 수 있는 아이콘이 나열돼요.

- [배 강화](/ko/features/ship-upgrading/) — 선박 강화에 필요한 재료 수량을 계산하고 보유 재고를 관리해요.
- [뉴스](/ko/features/news/) — 검은사막 공식 공지·업데이트·이벤트를 확인하고 실시간 알림을 받아요.
- [라이트스톤 조합](/ko/features/lightstone-combination/) — 원하는 효과를 가진 라이트스톤 조합을 검색해요.
- [물물교환](/ko/features/bartering/) — 물물교환에 필요한 파레이 소모량과 교역품 무게를 계산해요.
- [예약 종료](/ko/features/shutdown-scheduler/) <Badge type="warning" text="Windows 전용" /> — 지정한 시각에 컴퓨터가 자동으로 꺼지도록 예약해요.
- [색 카운터](/ko/features/color-counter/) — 인게임에서 색상 개수를 셀 때 쓰는 간단한 도구예요.
- [거래소 시세](/ko/features/trade-market/) — 아이템 시세를 검색하고, 등록 대기 목록과 자주 쓰는 프리셋을 실시간으로 확인해요.
- [월드보스](/ko/features/world-boss/) — 월드보스 출현 시간표를 확인하고 출현 임박 알림을 받아요.
- [인게임 오버레이](/ko/features/overlay/) <Badge type="warning" text="Windows 전용" /> — 게임 화면 위에 시계·월드보스·파티 모집 등의 정보를 겹쳐서 보여줘요.

이 외에도 [로그인](/ko/features/auth/)/[파티 찾기](/ko/features/party-finder/)/[방송 위젯](/ko/features/broadcast-widgets/) 기능은 홈 화면 아이콘 없이 각 페이지에 직접 접속해서 사용해요.

## 홈 화면 사용법

- 우상단 로그인 버튼으로 Discord 로그인 상태를 확인하고, 버튼을 눌러 로그인할 수 있어요.
- 가운데 기능 아이콘을 눌러 원하는 기능으로 바로 이동하세요. 창 너비에 따라 한 줄에 배치되는 아이콘 개수가 자동으로 조절돼요.
- 뉴스 영역에는 마감이 3일 이내로 임박한 이벤트가 있으면 우선 캐러셀로 보여주고, 없으면 최신 이벤트 5개를 보여줘요. 그 옆에는 최신 주요 업데이트와 연구소 소식 카드가 함께 나와요.
- 하단에는 공식 홈페이지, 인벤, 인벤맵, 가모스, 코덱스, bdolytics 등 자주 쓰는 외부 사이트 링크가 있어요.
- 우측 상단 톱니바퀴 아이콘으로 [설정](/ko/features/settings/) 화면으로, 하단의 "후원하기"로 후원 안내 페이지로, "문의"로 문의용 구글폼으로 이동할 수 있어요.

## 알아두면 좋은 점

- <Badge type="warning" text="Windows 전용" /> [인게임 오버레이](/ko/features/overlay/), [예약 종료](/ko/features/shutdown-scheduler/) 아이콘은 Windows 앱에서만 눌러서 이동할 수 있어요. 웹/안드로이드에서는 눌러도 "Windows 전용 기능이에요" 안내만 나오고 이동하지 않아요.
- Windows 앱은 창을 닫아도 [설정](/ko/features/settings/)에서 "트레이 상주"를 켜두면 완전히 종료되지 않고 트레이(작업표시줄 구석 아이콘)에 남아있어요. 트레이 아이콘을 좌클릭하면 창이 다시 보이고, 우클릭하면 보이기/숨기기/종료 메뉴가 나와요. 완전히 끄고 싶다면 트레이 메뉴에서 종료를 선택하세요.
- 창 크기와 위치는 홈 화면을 사용하는 동안 자동으로 저장돼서, 다음 실행 시 그대로 복원돼요. 따로 설정할 필요는 없어요.
- 화면 맨 아래에는 Karanda가 게임사(펄어비스)의 공식 서비스가 아닌 비공식 팬 서비스임을 알리는 문구가 항상 표시돼요.
