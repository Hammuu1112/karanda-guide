# 라이트스톤 조합

라이트스톤(광명석) 조합 목록에서 원하는 효과를 검색하고 조합 구성을 확인할 수 있어요.

## 이런 걸 할 수 있어요

- 조합 이름, 효과, 구성 광명석 이름으로 검색
- 여러 키워드를 동시에 만족하는 조합만 찾기(AND) 또는 하나라도 포함된 조합 찾기(OR)
- 일반 조합과 증폭 조합을 구분해서 보기

## 사용 방법

1. 검색창에 원하는 조합 이름, 효과, 또는 광명석 이름을 입력하세요. 입력하는 동안 자동완성 후보가 함께 나타나요(띄어쓰기 무시, 부분 일치).
2. 키워드를 여러 개 추가할 수 있어요. 기본값은 **OR 모드**라서 키워드 중 하나라도 일치하는 조합을 모두 보여줘요. 모든 키워드를 동시에 만족하는 조합만 보고 싶다면 AND 모드로 전환하세요.
3. "증폭 보기" 옵션(기본값 켜짐)으로 증폭 조합만 볼지, 일반 조합만 볼지 전환할 수 있어요.
4. 원하는 조합을 선택하면 구성된 광명석 목록과, 조합 고유 효과에 각 광명석 효과까지 합산된 전체 효과를 확인할 수 있어요. 같은 이름의 효과는 하나로 합쳐서 표시돼요.

## 알아두면 좋은 점

- 효과나 이름이 없는 항목(`-`)은 목록에 표시되지 않아요.
- 자동완성 후보는 일반 조합을 기준으로 만들어지지만, 실제 검색 결과에는 "증폭 보기" 설정에 따라 증폭 조합도 포함될 수 있어요.
- 조합/효과 정보는 게임 업데이트에 맞춰 갱신돼요.
