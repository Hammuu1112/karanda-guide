# Lightstone Combination

Search the list of lightstone combinations for a desired effect and check what makes up each combination.

## What you can do

- Search by combination name, effect, or component lightstone name
- Find combinations matching all your keywords (AND) or any of them (OR)
- View regular and amplified combinations separately

## How to use it

1. Type a combination name, effect, or lightstone name in the search box. Autocomplete suggestions appear as you type (whitespace ignored, partial match).
2. You can add multiple keywords. The default is **OR mode**, showing any combination that matches at least one keyword. Switch to AND mode to only show combinations matching every keyword.
3. The "Show amplified" toggle (on by default) switches between amplified-only and regular-only combinations.
4. Select a combination to see its component lightstones and its total effects — the combination's own effects plus every lightstone's effects combined. Effects with the same name are merged into one.

## Good to know

- Effects or names shown as a placeholder (`-`) are excluded from the list.
- Autocomplete suggestions are built from regular combinations, but the actual search results can also include amplified ones depending on the "Show amplified" setting.
- Combination and effect data is updated to match game patches.
