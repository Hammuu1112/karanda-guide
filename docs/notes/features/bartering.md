# Bartering

A tool for calculating parley consumption and trade good weight for bartering.

## What you can do

- Calculate total parley consumed across multiple exchange points
- Factor in parley reduction from trade vouchers, Value Pack, Cleia, and trade proficiency
- Calculate how much weight trade goods will take up on your ship

## How to use it

### Parley calculation

1. In settings (top-right), enter your trade proficiency, whether you have Value Pack, and your ship profile (including whether you're using Cleia). Every exchange point's actual consumption is automatically reduced based on these.
   - The reduction rate is **trade proficiency reduction + 10% for Value Pack + 10% for Cleia**, all added together. Turning on more of these stacks the reduction.
2. Your default parley is **1,000,000**. If you have Trade Vouchers, enter how many (0–99) — each one adds **250,000**.
3. Enter how many times you'll use each exchange point (0–999) to see how much parley it will consume.
4. Tap "Apply" to add that exchange point's consumption to your running total, resetting its count back to 0.
5. Use reset to start over — your parley resets back to 1,000,000.

### Weight calculation

1. Switch to the weight calculation tab.
2. Enter how many trade goods you have at each level (1–7); the total weight is calculated automatically using the fixed output weight per level (100–2000).
3. Goods not on the list can be added under "Etc" with a weight you enter yourself.
4. Reset sets every level back to 0, except "Etc," which returns to its default (1).

## Good to know

- The parley reduction formula and the 250,000-per-voucher value directly reflect the game's official numbers.
- You'll always have at least one ship profile — you can register several and switch between them as needed.
- Exchange point lists and required parley values can change with game patches, and the app is updated to match.
