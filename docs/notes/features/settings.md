# Settings

Customize the app's theme, font, region, notifications, and Windows behavior.

## What you can do

- Adjust theme (light/dark/system), font, and background/effect volume
- Set your game region (Korea/North America/Europe/Japan) — this also affects region-based features like the trade market, world boss, and news
- <Badge type="warning" text="Windows only" /> Configure start minimized and tray behavior
- Turn news/world boss notifications on or off and choose categories
- View support info, change log, and app info

## How to use it

### Display / Sound

- Choose light, dark, or system theme (follow your device setting). The default is **dark mode**.
- Choose from Maplestory, Noto Sans KR, Nanum Gothic, or Jua fonts. The default is Noto Sans KR.
- Adjust background/effect volume between 0–100 with the slider.

### Region

- The default region is **Korea (KR)**. Switching to North America/Europe/Japan updates every region-based feature — [Trade Market](/features/trade-market/), [World Boss](/features/world-boss/), [News](/features/news/), and [Party Finder](/features/party-finder/) — to match.

### Windows-only settings

- "Start minimized" launches the app with the window minimized.
- "Minimize to tray" keeps the app running in the tray instead of quitting when you close the window. Both are off by default.

### Notifications

1. Go to the notification settings screen (called "Push Notifications" on web/Android, "Notifications" on Windows).
2. Turn on news notifications and choose which categories you want (Notice/Update/Event/Lab). All are off by default.
3. On web/Android, turning on notifications immediately requests browser/device notification permission. If you deny it, notifications won't turn on — if you're not receiving them, check your device's notification permission first.
4. [World Boss](/features/world-boss/) and [Party Finder](/features/party-finder/) notifications each have their own toggle on their respective screens.

### Other pages

- "Support Karanda": how to support the project
- "Change Log": update history by version
- "App Info": current version and other app details

## Good to know

- Changing your region affects many features at once, so only switch it when you actually want to see a different server's data.
- Window size/position on Windows is saved automatically while you use the home screen — it's not something you set directly here.
- If notification permission was denied, toggling the switch on may silently have no effect. If that happens, double-check both the on-screen toggle and your actual notification settings.
