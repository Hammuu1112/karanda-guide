# In-game Overlay

<Badge type="warning" text="Windows only" />

Overlay a clock, world boss info, party recruitment, and more directly on top of your game screen.

## What you can do

- Check the following without alt-tabbing out of the game:
  - Clock (current time)
  - World boss HP bar and next boss info
  - Party/platoon recruitment posts
  - In-game Black Desert time
  - Notifications (new news/recruitment, etc.)
- Turn individual widgets on or off, and adjust their position and opacity
- Choose which monitor to display on (supports multi-monitor setups)

## How to use it

1. Tap the overlay icon on the home screen to open its settings.
2. Turn on the widgets you want to see (clock, world boss, party finder, game time, notifications) one by one.
3. Turn on "Edit Mode" to freely drag widgets around on top of the game screen. Positions are saved automatically. Use "Reset widget positions" to put everything back to its default spot.
4. Adjust each widget's opacity so it blends naturally with the game screen.
5. If you use multiple monitors, choose which one the overlay should appear on.
6. The world boss widget lets you toggle boss name display, and the party finder widget lets you exclude specific recruitment categories.

## Good to know

- The overlay runs as a separate transparent window from the game. Normally clicks pass straight through to the game — only in Edit Mode can you click and drag the overlay directly.
- After turning the overlay on, it takes a moment for widgets to appear — don't worry if they're not visible immediately.
- If your monitor setup changes (e.g., disconnecting an external monitor), the overlay automatically falls back to your primary monitor.
- Closing the app entirely also closes the overlay window.
- World boss info is linked live with the [World Boss](/features/world-boss/) screen, and party recruitment info with the [Party Finder](/features/party-finder/) screen.
